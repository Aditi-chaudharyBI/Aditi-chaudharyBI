## 🚀 Featured Projects

### 🚚 [Logistics MIS Reporting Automation](https://github.com/Aditi-chaudharyBI/Logistics-MIS-Reporting-Automation-)
> **SQL Server · Advanced Excel · KNIME · Power Query**

Designed and deployed an end-to-end automated MIS pipeline consolidating data from **4 operational systems** into a single source of truth. The dashboard tracks ₹61.8M in revenue, 5,000 shipments, carrier performance, and warehouse efficiency across pan-India operations.

**Impact:** ⏱️ Reduced daily report generation from **3 hours → 20 minutes**

---

### 🎯 [Customer Segmentation & Retention Analysis](https://github.com/Aditi-chaudharyBI/Customer-Segmentation-Retention-Analysis)
> **Python (Pandas, NumPy, Matplotlib) · Power BI · RFM Analysis · SQL**

Applied RFM (Recency, Frequency, Monetary) analysis across **10,500+ customers and 73,870+ transactions** (£23.96M revenue). Segmented customers into 10 behavioral groups and classified churn risk, surfacing that 33.5% of customers were high-risk.

**Impact:** 📈 Delivered projections that guided campaigns achieving **+12% retention improvement**

---

### 📊 [HR Employee Attrition Analysis Dashboard](https://github.com/Aditi-chaudharyBI/HR-Employee-Attrition-Analysis-Dashboard)
> **Python (Pandas) · Power BI · SQL · Predictive Analytics**

Ran predictive analytics on **1,470 employee records** to surface top attrition drivers — overtime, job satisfaction, and tenure. Built correlation heatmaps and feature importance charts compiled into a Power BI dashboard for HR leadership.

**Impact:** 🔍 Enabled department-level and salary band monitoring to inform proactive retention decisions

---

### 🏪 Franchise Performance Dashboard *(Enterprise Project)*
> **Power BI · SQL Server · Advanced DAX**

Built an end-to-end BI solution covering **50+ regional franchise locations** with KPI cards for Total Revenue, AOV, and MoM Growth. Implemented Row-Level Security (RLS) for regional data access control and identified the **top 5 underperforming locations** to guide Q3 expansion strategy.
